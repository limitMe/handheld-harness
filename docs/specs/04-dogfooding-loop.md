# 04 · Dogfooding Loop

> **English summary.** The full spec is in Chinese: [`docs/zh-CN/specs/04-dogfooding-loop.md`](../zh-CN/specs/04-dogfooding-loop.md).

**Status:** Implemented

This spec establishes the workflow of developing HANDHELD.AI with HANDHELD.AI: the user requests changes through the app, the agent edits the repository, the user previews the result and commits after verifying, and a broken build can always be repaired. It is the end of stage A, and all stage B specs are implemented through this loop once it passes. In scope are the dual-instance topology, cross-profile server sharing, stable-version scripts and a desktop shortcut, bootstrap rules in AGENTS.md, and a recovery guide; no new product features are added. The key topology is a stable instance built from a git worktree that runs the last known-good build in fullscreen and drives a dev instance running `npm run dev`, both sharing one detached OpenCode server keyed by workspace and version so they see the same sessions. Because the stable instance is unaffected by edits to the working tree, the user can always keep commanding the agent even when the dev instance breaks. Node scripts provide `stable:setup`, `stable:update` (a clean tree and a passing check are required, it fast-forwards and tags, and it builds to a temporary directory before swapping), `stable:rollback`, `stable:start` (detached, fullscreen), and `stable:shortcut` for touch or gamepad launching, while the status bar shows a `STABLE` or `DEV` badge derived from the profile. AGENTS.md gains bootstrap rules that forbid terminating processes or launching another GUI, restrict editing to the main repository, require `check` after every change, warn that dependency changes need the dev instance closed, and prohibit commits without explicit user instruction, with a recovery table and a daily workflow documented separately. Automated delivery was verified for script idempotency, shortcut creation, guard paths, and `npm run check`, while the GUI-dependent acceptance steps remain manual on the handheld.
