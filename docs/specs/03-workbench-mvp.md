# 03 · Minimal Viable Workbench

> **English summary.** The full spec is in Chinese: [`docs/zh-CN/specs/03-workbench-mvp.md`](../zh-CN/specs/03-workbench-mvp.md).

**Status:** Implemented

This spec builds the minimal UI on top of the spec 02 engine: users can converse with the agent using a keyboard, touch, and Win+H voice input, respond to permission requests and questions, and switch between tasks. It delivers renderer state management, a chat list with Markdown, tool calls, and streaming, a composer, permission and question cards, abort, a temporary task switcher, a status-bar title, an error banner, font zoom, and a fake engine. Excluded are the gamepad and focus systems, sticky collapse and composer collapse/expand, the task map, the system menu, in-app voice, list input and operation hints, and motion polish, which belong to later stage B specs. Key decisions include a zustand store sliced by engine, all events applied through a tested pure `applyEngineEvent` function keyed by `SessionRef`, re-pulling a snapshot on ready or reconnect, reopening the last session or starting a new task, and never pre-creating empty sessions. Messages render with react-markdown, remark-gfm, and rehype-highlight; external links are opened by the main process with an http/https whitelist; and streaming text parts re-render at most every 50 ms. The composer must be a native textarea so IME, the touch keyboard, and Win+H work and so cursor APIs remain available, with Enter to send, Shift+Enter for a newline, an `isComposing` guard, and an Esc abort while busy. Permission cards offer once/always/reject with the always option hidden when the engine lacks that capability, questions support single or multiple choice with submit or ignore, and all capability-based behavior must read capabilities rather than branch on engine kind. A temporary task switcher covers filtering and switching, zoom is persisted to settings, and touch targets are at least 44 px. Verification is `npm run check` plus an e2e suite running on a fake engine that replays recorded fixtures and offers special scenarios and capability overrides, followed by manual acceptance on the handheld with the real engine.
