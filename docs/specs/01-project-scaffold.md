# 01 · Project Scaffold

> **English summary.** The full spec is in Chinese: [`docs/zh-CN/specs/01-project-scaffold.md`](../zh-CN/specs/01-project-scaffold.md).

**Status:** Implemented

This spec establishes an Electron + React + TypeScript project that starts with `npm run dev` and hot module replacement on the handheld, and that supports type checking, linting, unit tests, and an end-to-end smoke test. It also ships gamepad and microphone debug pages to validate the two riskiest research areas early, and an `AGENTS.md` for AI agents. In scope are the project structure, build and dev scripts, security baseline, main/preload/renderer skeletons, typed IPC, logging, a settings-storage skeleton, multiple profiles, debug pages, test infrastructure, and repository conventions, while chat UI, OpenCode integration, the formal input and focus systems, and packaging are deferred to later specs. Key decisions include npm with a committed lockfile, pinned exact dependency versions, Electron 44 with electron-vite 5, React 19, Base UI accessed only through the local `ui/` wrapper, Tailwind 4 with semantic tokens separated from theme values, zod validation, electron-log, Vitest, and Playwright `_electron`. The main process reads a profile environment variable before `app.whenReady()`, takes a per-profile single-instance lock, creates a frameless window with strict `webPreferences`, allows only audio media permissions, sets a CSP, and stores settings atomically with a backup when validation fails. IPC contracts live in `src/shared/ipc.ts`, the preload exposes only `window.handheld`, and the renderer provides a StatusBar plus gamepad and microphone debug overlays. Verification covers a clean `npm ci` with no node-gyp compilation, dev startup, renderer HMR, main-process hot restart, build/start and F11 fullscreen, `npm run check`, e2e with screenshots, the security baseline, multi-profile coexistence, invalid-settings fallback, the debug pages, and lint-enforced UI boundaries. The implementation record documents deviations such as building in the repository root and the extra `--watch` and `clean` scripts.
