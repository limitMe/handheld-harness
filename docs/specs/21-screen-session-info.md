# 21 · Screen: Session Info

> **English summary.** The full spec is in Chinese: [`docs/zh-CN/specs/21-screen-session-info.md`](../zh-CN/specs/21-screen-session-info.md).

**Status:** Implemented

This spec adds a session-info page on top of Current Work that shows context/cost metrics and lets the user pick a working directory before the session is created and change thinking effort at any time. The page is a fullscreen overlay opened from an INFO status-bar button (no keybinding, Back closes it) and displays message count, provider, model name, context limit, current token usage, context percentage, cost, creation time, and last-activity time. Two directly actionable rows sit at the top: the working directory, editable only while the task is new via the native directory picker and read-only once the session exists, and the thinking effort, chosen from model variants through a `ChoiceDialog` that writes to a pending new session or calls `setSessionEffort` on an existing one. The abstraction layer grows in a backend-agnostic way with `EngineCapabilities.messageUsage`/`modelEffort`/`sessionDirectory`, `SessionSummary.effort`/`directory`, `ChatMessage.usage`, model `contextLimit`/`variants`, and `AgentEngine.setSessionEffort`, and the renderer must branch on capabilities only, never on the backend. Out of scope are charts/reports, mid-session directory migration, and a default-effort setting; per-session directories are fixed at creation (P-22) and efforts persist in a `<key>.efforts.json` file (P-23). Implementation maps the OpenCode SDK v2 fields in `normalize.ts`/`adapter.ts`, adds `app:pickDirectory` and `engine:setSessionEffort` IPC, and adds `SessionInfoPage.tsx`, pure session-info calculations, store pending fields, a fake-engine implementation, and tests. Verification is `npm run check` (398 unit tests) plus new session-info and normalize tests; the biggest open manual item is whether `session.list({})` returns sessions from custom directories across projects, and the INFO button was later changed to a toggle.
