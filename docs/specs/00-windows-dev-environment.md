# 00 · Windows 11 Development Environment

> **English summary.** The full spec is in Chinese: [`docs/zh-CN/specs/00-windows-dev-environment.md`](../zh-CN/specs/00-windows-dev-environment.md).

**Status:** Implemented

This spec readies a Windows 11 handheld to clone, install, run, and test the repository, to run an AI coding agent for later specs, to configure at least one LLM provider in OpenCode, and to confirm that microphone, gamepad, and Windows voice input (Win+H) all work. It covers system settings, tool installation, Git and credential setup, AI agent installation, and device capability checks, while explicitly excluding project creation (spec 01) and native build toolchains, which are installed only when a later spec needs them. The environment is built on PowerShell 7, with tools installed via winget, Developer Mode and long-path support enabled, and Git configured for LF line endings and long paths. The repository is expected at a short path such as C:\dev\handheld-harness and must not live inside a OneDrive-synced folder. The OpenCode CLI is pinned to 1.18.34 and is used for credentials, as the implementing agent, and as a TUI fallback; credentials are entered interactively and an agent must never type or store API keys. The gamepad must be switched to XInput mode rather than a desktop or mouse mode, and Win+H voice input is the bootstrap dictation method. Verification is a PowerShell check script whose items must all report OK, plus manual confirmation of the OpenCode smoke reply, Win+H dictation, gamepad detection in joy.cpl and a browser test page, and a completed environment record.
