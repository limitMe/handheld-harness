# 13 · Screen: Current Work

> **English summary.** The full spec is in Chinese: [`docs/zh-CN/specs/13-screen-current-work.md`](../zh-CN/specs/13-screen-current-work.md).

**Status:** Implemented (dictation and text-edit hooks still pending)

This spec defines the main "Current Work" screen: the largest area shows the current task, and nothing else appears besides a narrow status bar, the chat transcript and the composer. User messages are right-aligned and agent messages left-aligned, and the composer is a small centered bar when idle and a floating expanded field when focused or holding a draft, overlaying the chat without reflowing it.

The key decisions are sticky collapsing of user messages, where a user message pins to the top and truncates to a single line while a long reply follows, is pushed off by the next user message, and restores (or expands when focused) when scrolled back to; and a floating composer whose navigation, two-stage activation exit, and send/delete/list-input/text-edit/dictate actions are delegated to specs 10, 11, 12, 16 and 17. Permission and question cards auto-focus and auto-activate and reuse action hints: the question card moves a highlight across options and submit/ignore with A to confirm or toggle and B to reject via `rejectQuestion`, while the composer stays collapsed during a card and focus returns afterward. The current model is intentionally not shown on this screen. Dictation and text-edit hooks remain placeholders, so those actions are provided by the ActionMap but not yet functional. Verification uses unit tests for round grouping and stick detection, question-card behavior and composer collapse, plus e2e coverage of collapse/expand, auto-activating cards, permission-card hints and sticky collapse; later revisions added agent output cards split into intermediate and latest-reply cards, a full-screen card viewer, soft code highlighting and a session-error card.
