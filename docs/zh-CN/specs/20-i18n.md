# 20 · 国际化（i18n）

> 阶段 B · 方向性 spec。

## 目标

为工作台提供统一的多语言抽象层，内置英文与简体中文两套文案；用户可以在系统菜单里切换语言，选择即时生效并持久化，重启后保持。

## 范围

**包含**：

- 语言抽象层：语言模式（`system` / `en` / `zh`）、按操作系统语言解析、目录（catalog）组织与回退。
- 渲染进程 i18n 单例（`react-i18next`），覆盖全部用户可见文案：状态栏、当前工作、任务地图、系统菜单、调试页、对话框、操作提示、通知。
- 设置项 `settings.ui.language` 与「显示与提示 › 语言」设置行。
- 单测：语言解析、目录键一致性、动作 / 上下文的文案覆盖。

**不包含**：

- 主进程产出的引擎诊断文案（`EngineStatus.error` / `hint`、日志）仍为英文，属于引擎层的诊断数据，后续需要时再接入共享 i18n。
- 引擎返回的会话标题、模型名、命令描述等数据不翻译。
- 复数 / 性别等本地化规则（当前两套目录都用不到复数）。

## 依赖

- 15（系统菜单，语言设置行）、12（操作提示的文案来自动作标签）。

## 设计

- **目录放 shared**：`src/shared/i18n/locales/{en,zh}.ts` 以 `satisfies TranslationCatalog` 约束形状；`src/shared/i18n/index.ts` 定义 `LANGUAGE_MODES`、`resolveLanguage`、`resources`。shared 只依赖 i18next（纯 TS，不含 electron / react），主进程将来也可复用。
- **语言模式**：`system | en | zh`。`resolveLanguage('system', locale)` 在 locale 以 `zh` 开头时解析为 `zh`，否则回退英文（`fallbackLng` 也是 `en`）。
- **渲染层单例**：`src/renderer/src/i18n/index.ts` 用 `initReactI18next` 注册默认实例并同步初始化（`initAsync: false`）；组件用 `useTranslation`、非 React 代码用 `i18n.t`，测试无需 provider。
- **即时生效**：`useLanguageSync`（在 `App` 挂载）读取 `settings.ui.language` 并 `changeLanguage`，订阅 `settings:changed`，并监听 `languagechange` 以支持 `system` 模式。
- **设置行**：放在「显示与提示」分类末尾的独立「语言」分组，用 `ChoiceDialog`（枚举值，非连续值），遵循 15 的即时保存约定。放在末尾是为了不改变既有分类与设置行的导航顺序。
- **动作 / 上下文文案**：`shared/actions.ts` 与 `shared/bindings.ts` 的英文标签保留为默认值，渲染层用 `t('actions.<id>', { defaultValue })` / `t('contexts.<id>', { defaultValue })`，缺键时回退英文。

## 验收方向

- 打开系统菜单 › 显示与提示 › 语言，在「跟随系统 / English / 简体中文」之间切换，整个界面即时切换语言。
- 重启后语言保持；选 `system` 时跟随操作系统语言。
- `npm run check` 通过，包含目录键一致性与覆盖检查。

### 与 spec 的出入 / 决策

- **不使用 i18next 的复数能力**：计数类文案统一用 `{{value}}` 而非 `{{count}}`，避免触发复数解析。
- **语言设置行放在「显示与提示」末尾并单独分组**：spec 15 的 5 个分类保持不变，避免打乱既有导航与自动化用例。
- **主进程诊断文案不本地化**：引擎 `error` / `hint`（如 “No workspace configured”）仍为英文，见「不包含」。
- **复用 shared 的英文标签作为 `defaultValue`**：即使目录漏键也不会显示裸 key。

### 扩展（多语言）

（2026-10-10。）语言集合改为**开放**：`LANGUAGE_MODES` 增加 `zh-Hant`、`ja`、`ko`、`es`、`fr`、`de`、`ru`；`resolveLanguage` 按系统 locale 前缀解析（`zh-Hant`/`zh-TW`/`zh-HK`/`zh-MO` → `zh-Hant`，其余 `zh-*` → `zh`，其他语言按前缀匹配），未知 locale 回退 `en`。

维护约定（详见根目录 `AGENTS.md` 的「Localization」）：

- **新功能只新增 `en` + `zh`**，`npm test` 强制两者 key 完全一致、占位符匹配。
- **其他语言在专门的多语言对齐 commit 中补齐**；次级目录允许落后，缺 key 时回退英文。
- 单测对次级目录放宽为「key 是 `en` 的子集 + 占位符一致 + 无空串」，并按 `en` 校验动作 / 上下文覆盖。
